3
Lương + Rule Tài xế
💰

📍 Vị trí

Tab T.Quan → mở mục Thu nhập → nhập 3 ô.

💵 3 ô nhập

ÔÝ nghĩa
LCBLương cơ bản
Bưu cụcPhụ cấp bưu cục
Tài xếPhụ cấp tài xế (xem rule bên dưới)

Bấm "Lưu cấu hình tháng này" để lưu.

⚡ RULE QUAN TRỌNG — Phụ cấp Tài xế Tài xế chỉ được cộng vào lương khi Đơn Giao ≥ 1.500/tháng.

• < 1.500 → không cộng (bỏ qua ô Tài xế)
• ≥ 1.500 → cộng đầy đủ

→ App hiện banner cảnh báo ngay dưới ô nhập, báo còn thiếu bao nhiêu đơn.

📐 Công thức

Lương 1 công = (LCB + Bưu cục + Tài xế) / ngày tối đa

Ngày tối đa:
  • Tháng 2  → 24 ngày
  • Tháng khác → 26 ngày

Số công = đếm ngày có:
  Giao + (Lấy / 6) + Hoàn ≥ ngưỡng
  • Miền:   ≥60 = 1 công, ≥30 = 0.5 công
  • HCM/HN: ≥80 = 1 công, ≥40 = 0.5 công

Tích lũy = Lương 1 công × số công
📅 Lưu theo tháng Lương + Hạng lưu riêng theo từng tháng. Đổi tháng → tự chuyển cấu hình tháng đó.
Riêng Khu vực (Miền / HCM-HN) chọn 1 lần, áp dụng mọi tháng.

5
Backup Cloud
☁️
💾 Tại sao cần Xóa cache trình duyệt / reset máy → mất data. Cloud backup giúp khôi phục.

🔑 Setup 1 lần (5 phút)

  1. Vào github.com/settings/tokens (đăng nhập GitHub)
  2. Bấm Generate new token (classic)
  3. Note: spx-backup · Expiration: No expiration
  4. Scope: tích gist → bấm Generate
  5. Copy token ghp_...
  6. Mở app → Menu ☰ → Backup & Cloud → dán token
  7. Bấm 🔌 Kiểm tra → ☁️ Backup (tạo Gist lần đầu)
  8. Tích "Tự động backup" → từ đó tự sync mỗi thay đổi

🔄 Khôi phục khi mất data

  1. Menu ☰ → Backup & Cloud
  2. Bấm ⬇️ Khôi phục từ Cloud
  3. Chọn GHI ĐÈ (xóa hết cũ) hoặc THÊM VÀO (giữ cũ + thêm mới)

📁 Backup file JSON (offline)

  • 💾 Lưu file — tải file về máy
  • 📥 Nạp file — chọn file JSON đã lưu
  • 🔄 Phục hồi tự động — khôi phục từ vault (bản sao lưu ngầm)

Xử lý sự cố
🔧

🐛 OCR đọc sai số

Chụp lại ảnh rõ nét hơn (đủ sáng, không rung). Nếu vẫn sai → mở modal → sửa tay số bị sai → Lưu.

🎯 Không nhận diện được tab

App hiện modal "Chọn loại đơn". Chọn Giao / Lấy / Hoàn thủ công (1 lần/ảnh). Ảnh tiếp theo nếu rõ sẽ tự nhận.

🔄 App không cập nhật bản mới

  1. Menu ☰ → 🔄 Kiểm tra cập nhật
  2. Có banner "🎉 Có bản mới" → bấm Cập nhật
  3. Nếu vẫn cũ → gỡ app → cài lại

💥 Mất dữ liệu

Menu ☰ → Backup & Cloud → ⬇️ Khôi phục từ Cloud (nếu đã setup) hoặc 🔄 Phục hồi tự động.

⚠️ Báo "Đã tồn tại bản ghi cùng số liệu"

Ngày đó đã nhập rồi. Muốn sửa → vào Nhật ký → bấm Sửa.

Đóng app hoàn toàn → mở lại.
